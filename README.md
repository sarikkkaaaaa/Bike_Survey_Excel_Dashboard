# 🚲 Bike Sales Analysis – Excel Dashboard

An interactive **Bike Sales Analysis Dashboard** built using Microsoft Excel to explore customer purchasing behaviour and identify patterns across different demographic and lifestyle factors.

The project focuses on transforming raw survey data into meaningful insights through data cleaning, PivotTables, PivotCharts, KPI cards, and interactive slicers.

## 🎯 Project Objective

The objective of this project is to analyse customer survey data and understand how different factors relate to bike purchasing behaviour.

The analysis explores customer demographics, income levels, marital status, number of children, commute distance, car ownership, and regional patterns to identify trends that can support business decision-making.

## 📌 Key Performance Indicators (KPIs)

The dashboard includes five key metrics:

- **Total Survey Records:** 1,026
- **Bikes Purchased:** 495
- **Bikes Not Purchased:** 531
- **Purchase Rate:** 48.25%
- **Non-Purchase Rate:** 51.75%

## 📈 Dashboard Analysis

The dashboard covers five major areas:

### 1. Gender Analysis
Examines bike purchasing behaviour across male and female customers.

### 2. Marital Status & Family Analysis
Explores how marital status and the number of children relate to bike purchasing patterns.

### 3. Regional Analysis
Compares bike purchasing patterns across different geographical regions.

### 4. Commute Distance Analysis
Investigates the relationship between customers' commute distances and bike purchasing behaviour.

### 5. Occupational Analysis
Explores customer distribution across different occupational groups and income categories.

## 💡 Key Insights

- Male customers account for a higher number of bike purchases than female customers.
- Single customers without children represent an important purchasing segment.
- Bike purchases are higher among customers with shorter commute distances.
- North America records the highest number of bike purchases across the regions analysed.
- Middle-income customer groups contribute significantly to bike purchases.
